# Gutierrez Systems

**Software, automatización y sistemas operativos para procesos reales.**

Gutierrez Systems desarrolla soluciones tecnológicas orientadas a problemas operativos, administrativos y documentales concretos, con énfasis en trazabilidad, mantenibilidad y seguridad.

## Qué construimos

- aplicaciones web e internas para procesos operativos;
- automatización de tareas, reportes y flujos administrativos;
- herramientas para gestión documental y verificación;
- sistemas de soporte a operación en campo;
- prácticas de calidad, CI y documentación técnica.

## Productos y líneas activas

- **GS ContractOps** — producto en descubrimiento y diseño para planeación, ejecución, trazabilidad y supervisión de contratos con operación en campo.
- **EMINSER — Cierre de Nómina** — aplicación privada para procesos operativos de asistencia y revisión de cierre mensual.
- **GS Document Verification** — producto privado orientado a gestión y verificación documental.
- **Gutierrez Systems Web** — presencia web corporativa.

## Conocimiento y gobierno

La documentación viva de producto, descubrimiento, procesos y roadmap se gestiona en Notion. GitHub se usa para código, arquitectura técnica, ADR, CI, runbooks y estándares versionados.

La base de conocimiento técnico interna vive en `gs-knowledge-base` y permanece privada.

## Principios

1. Evidencia antes que afirmaciones.
2. Seguridad por defecto.
3. Cambios relevantes mediante ramas, Pull Requests y validaciones.
4. Separación clara entre productos, conocimiento interno y colaboraciones externas.
5. Documentación suficiente para permitir mantenimiento y transferencia de contexto.

## Colaboraciones externas

Aquality se considera una colaboración técnica externa. No pertenece a Gutierrez Systems y no se presenta como producto propio.

## Estado legal y de marca

La presencia técnica de Gutierrez Systems en GitHub no debe interpretarse por sí sola como prueba de una persona jurídica constituida. Las referencias legales y comerciales deben ajustarse siempre al estado formal vigente.
